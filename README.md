## 🛠️ Technology Stack

- **HTML5:** Semantic architecture (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<table>`, `<form>`, `<footer>`).
- **CSS3:** Custom properties (`:root`), Flexbox, CSS Grid, media queries (375px, 768px, 1280px).
- **Bootstrap 5.3:** 12-column responsive layout, native dark mode (`data-bs-theme="dark"`), navbar toggle, accordion, modal.
- **Bootstrap Icons & Google Fonts:** `Inter` and `Rajdhani`.

---

## 🎯 Target Audience & Theme Rationale

Designed specifically for university students and competitive esports gamers needing high-performance hardware (RTX 4080/4090, 240–360Hz monitors) in a comfortable environment. The visual identity uses a clean, matte dark-violet aesthetic without eye-straining neon glows for extended gaming and training sessions.
