Game cover images for the library (zones.html, section "Game library")

Each game has a cover in the "cover" field of REQ.games (js/data.js).
The files here are official promotional artwork of the games, saved as JPG
(max 960 px wide). They are used only to identify each title.

Credits (also on the About page and in the report):
Apex Legends and Fortnite (Respawn, Epic Games), Call of Duty: Warzone (Activision), Counter-Strike 2 (Valve), Cyberpunk 2077
(CD Projekt Red), Dota 2 (Valve), EA Sports FC 26 (EA), Forza Horizon 5
(Microsoft, Playground Games), League of Legends (Riot Games), Rocket League
(Psyonix), Tekken 8 (Bandai Namco), Valorant (Riot Games).

To replace an image, save the new file with the same base name and set its
path in js/data.js. Keep the aspect ratio near 16:10; the site crops with object-fit.
